# Neko Desktop 设计文档

## 核心理念
Neko Desktop 不是换壁纸/换图标/换颜色的 KDE 主题，而是在内核与 Plasma 之间增加一层「人格化桌面层」，最终效果是：电脑会回应、会变化、有状态、有生命感。

## 语言设计
- 中文优先，同时支持英文，格式：`中文 / English`
- 禁止日文

## 时间系统
| 时段 | 主题 |
|------|------|
| 06:00-12:00 清晨 | 明亮 / 粉色 / 活跃 |
| 12:00-18:00 工作 | 稳定 / 清晰 |
| 18:00-24:00 夜晚 | 深色 / 安静 |
| 00:00-06:00 深夜 | 黑紫 / 低亮度 |

## 玻璃效果
不是纯透明 (opacity 0 不可接受)，而是：透明(10-20%) + 黑色遮罩(15-30%) + 模糊(16-40px)。

## 安全安装
步骤：检测 → 备份 → 安装 → 测试 → 恢复。备份目录 `~/.config/neko-backup-日期`。

## 最终形态
```
Linux + KDE + Neko Layer = 人格化计算环境
```
